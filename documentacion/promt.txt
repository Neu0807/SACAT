Registro de Trabajador Fase 1 (Inicial Responsabilidad de Gestión Humana)

Paso 1 - Datos personales.
- tipo de documento de identificacion 
	observacion: debe mostrar solo los registros v, p y e.
- cedula / pasaporte
	observacion: ahora se llamara "documento de identificacion", cuando se seleccione el tipo de documento "v" que significa cedula venezolana, entonces debe tener la validacion ya sea por via ajax, que debe tener al menos minimo 6 caracteres, maximo 9, estos deben estar conformados por numeros, no debe poseer signos de puntuacion o especiales. En caso de seleccionar tipo de documento "e", tambien debe tener al menos minimo 6 caracteres y maximo 9, estos deben estar conformados por numeros, estos numeros deben estar a partir del rango 80000000 según el saime, quien proporciona cedulas a extranjeros a partir de ese correlativo, estos no deben poseer signos de puntuacion o especiales. En el caso de seleccionar tipo de documento "p", entonces debe poseer minimo 6 caracteres y maximo 12, debe permitir alfanumerico, no debe permitir signos de puntuacion o especiales.
- espacio para adjuntar documento de identidad (nuevo)
	observacion: deberia permitir formato pdf o imagen (jpg, jpeg, png), posteriormente en el futuro crearemos una funcion que permita al menos leer de estos archivos el numero de cedula y la fecha de vencimiento y fecha de nacimiento de la misma. como validacion de que no se adjunte un documento que no posea dichos datos.
- fecha de vencimiento de documento de identidad (nuevo)
	observacion: formato MM/AAAA y DD/MM/AAA
- fecha de nacimiento
	observacion: esta debe permitir a personas que según su fecha de nacimiento a la fecha del dia posean mínimo 16 años. Por ende las fechas como por ejemplo 2026 debe estar bloqueado para seleccion ya que solo permitira fechas que indiquen que la persona es mayor de 16 años de edad.
- lugar de nacimiento
- es naturalizado?
	observacion: en caso de ser si, desplegará 3 campos llamados nro de gaceta, un campo tipo pregunta es extraordinaria? y fecha de gaceta y estos campos deben ser requeridos. en caso de estar marcado como no, entonces, no muestra los campos y además se guardan como nulos.
- nro gaceta
	observacion: debe ser solo valores numericos, con maximo de 6 digitos, no debe permitir signos especiales o de puntuacion.
- es extraordinaria? campo nuevo
	observacion: este debe permitir solamente seleccion según la base de datos, que deberia ser un booleano (true, false).
- fecha de gaceta
	observacion: formato debe ser DD/MM/AAAA
- primer nombre
	observacion: debe permitir solamente caracteres tipo letra, ademas permitir espacios para nombres compuestos, guiones, apostrofes y acentos, asi como las eñes y la dierisis, sin embargo debe prohibirse numeros, signos especiales que no se encuentren permitidos o descritos anteriormente.
- segundo nombre
	observacion: debe permitir solamente caracteres tipo letra, ademas permitir espacios para nombres compuestos, guiones, apostrofes y acentos, asi como las eñes y la dierisis, sin embargo debe prohibirse numeros, signos especiales que no se encuentren permitidos o descritos anteriormente.
- primer apellido
	observacion: debe permitir solamente caracteres tipo letra, ademas permitir espacios para nombres compuestos, guiones, apostrofes y acentos, asi como las eñes y la dierisis, sin embargo debe prohibirse numeros, signos especiales que no se encuentren permitidos o descritos anteriormente.
- segundo apellido
	observacion: debe permitir solamente caracteres tipo letra, ademas permitir espacios para nombres compuestos, guiones, apostrofes y acentos, asi como las eñes y la dierisis, sin embargo debe prohibirse numeros, signos especiales que no se encuentren permitidos o descritos anteriormente.
- sexo
	observacion: segun lo que se encuentre la base de datos, esto sera un campo desplegable de unica seleccion, es decir solo se puede seleccionar un registro.
- estado civil
	observacion: segun lo que se encuentre la base de datos, esto sera un campo desplegable de unica seleccion, es decir solo se puede seleccionar un registro.
- boton de guardar y continuar
	observacion: debe redirigir al siguiente paso. (en este caso al paso 2)
- boton cancelar
	observacion: debe redirigir a la pagina de inicio

observacion general: todos los campos deben ser requeridos, excepto segundo nombre, segundo apellido, todo lo demas debera guiarse con su observacion como por ejemplo el campo es naturalizado, el cual sera requerido solo si esta la pregunta en si. predeterminado la pregunta es naturalizado debe estar en no o apagado.

Paso 2 - Contacto Personal (Anteriormente el paso 3 - contactos)
- tipo de contacto 
	observacion: para este caso mostrar solo correo electronico y telefono movil
- valor
	observacion: en caso de ser correo electronico, debera validar dentro de su tabla un patron de valores, el cual posee como la regla de lo que debe permitir para que esto lo haga el ajax. En caso de ser telefono movil, de igual manera debe validar dentro de su tabla el patron de valores, el cual posee la regla de lo que debe permitir y que esto lo haga el ajax en tiempo real.
- es principal?
	observacion: solo se debe permitir seleccionar el booleano true por tipo de contacto, es decir, solo puede registrar como true 1 correo electronico y 1 telefono movil. los demas deben quedar como respaldos, es decir con el valor es principal en false.

observacion general: se ocultarán los campos que tenian que ver con la tabla de contactos de emergencia. y todos los campos deben ser requeridos, la pregunta es principal debe ser predeterminada en no o apagada, para que el usuario pueda decidir.

paso 3 - Asignacion Laboral (Antes el paso 8 - datos laborales)
- nivel jerarquico
- unidad organizativa
- ubicacion fisica
- regimen (tipo)
- categoria de personal
- cargo generico
- cargo estructural
- codigo de nomina
- fecha de ingreso

observacion general: todos seran campos requeridos, excepto el codigo de nomina, que aun esta en definicion, no daremos mayor descripcion de este paso ya que aun esta en construccion.

paso 4 - Comprobante y Emisión de Credenciales (Nuevo)
Este paso debe indicar que el registro del trabajador fue exitoso, mostrar un resumen de todos los campos que fueron llenados como una ficha inicial del trabajador y además emitir sus credenciales para ingresar al sistema, en este caso su nombre de usuario el cual por defecto será su cedula o documento de identidad, y una contraseña generica el cual debe estar compuesta por los siguientes parametros: Minimo 8 caracteres, Maximo los caracteres que desee, debe poseer al menos 1 letra mayuscula, 1 letra minuscula, al menos 1 numero, y 1 signo de puntuacion o especial como puede ser ($#%&.*) y otros que apoyen a ser del sistema más seguro y 1 letra Ñ en mayuscula o 1 letra ñ en minuscula. Esto como contraseña o clave temporal, el cual por supuesto deberá cambiar la primera vez que ingrese al sistema, se debe realizar esa notificacion que es una clave temporal y debe ser cambiada la primera vez que ingrese al sistema. Momentaneamente se crearán dichos usuarios con roles administradores por defecto, ya que aún no tenemos más roles ni definicion de permisos del sistema.

    document.addEventListener('DOMContentLoaded', function() {
        const form = document.getElementById('formPaso1');
        const btnSiguiente = document.getElementById('btnSiguiente');
        const checkNat = document.getElementById('checkNaturalizado');
        const divGaceta = document.getElementById('divGaceta');

        // Detectar tema para SweetAlert
        const isDark = document.documentElement.getAttribute('data-bs-theme') === 'dark';
        const swalBg = isDark ? '#1E293B' : '#ffffff';
        const swalColor = isDark ? '#F8FAFC' : '#0F172A';

        // 1. Mayúsculas automáticas
        form.querySelectorAll('.text-uppercase').forEach(input => {
            input.addEventListener('input', function() { this.value = this.value.toUpperCase(); });
        });

        // 2. Manejo de Naturalización (Regla de negocio)
        checkNat.addEventListener('change', function() {
            if (this.checked) {
                divGaceta.style.display = 'block';
                divGaceta.querySelectorAll('input').forEach(i => i.setAttribute('required', ''));
            } else {
                divGaceta.style.display = 'none';
                divGaceta.querySelectorAll('input').forEach(i => { i.removeAttribute('required'); i.value = ''; });
            }
        });

        // 3. ENVÍO AJAX (El que sí guardaba el 30-03)
        form.addEventListener('submit', function(e) {
            e.preventDefault(); // BLOQUEO DE REFRESH GARANTIZADO
            
            // Validación manual rápida
            let isInvalid = false;
            form.querySelectorAll('[required]').forEach(input => {
                if (!input.value || !input.value.trim()) {
                    input.classList.add('is-invalid');
                    isInvalid = true;
                } else {
                    input.classList.remove('is-invalid');
                }
            });

            if (isInvalid) {
                Swal.fire({ 
                    icon: 'warning', title: 'Atención', 
                    text: 'Por favor complete todos los campos obligatorios (*)',
                    background: swalBg, color: swalColor 
                });
                return;
            }

            // Efecto Visual
            const originalText = btnSiguiente.innerHTML;
            btnSiguiente.disabled = true;
            btnSiguiente.innerHTML = '<span class="spinner-border spinner-border-sm me-2"></span> PROCESANDO...';

            // ENVÍO AL BACKEND
            fetch("{% url 'guardar_paso1' %}", {
                method: "POST",
                body: new FormData(form),
                headers: { "X-CSRFToken": "{{ csrf_token }}" }
            })
            .then(res => res.json())
            .then(data => {
                if (data.success) {
                    Swal.fire({
                        icon: 'success', title: '¡Éxito!',
                        text: 'Datos personales registrados.',
                        timer: 1500, showConfirmButton: false,
                        background: swalBg, color: swalColor
                    }).then(() => {
                        window.location.href = data.next_url || "{% url 'registro_paso2' %}";
                    });
                } else {
                    Swal.fire({ 
                        icon: 'error', title: 'Error', 
                        text: data.error || 'Ocurrió un error al guardar.',
                        background: swalBg, color: swalColor 
                    });
                    btnSiguiente.disabled = false;
                    btnSiguiente.innerHTML = originalText;
                }
            })
            .catch(err => {
                console.error("Error en Step 1:", err);
                Swal.fire({ 
                    icon: 'error', title: 'Error de Red', 
                    text: 'No se pudo conectar con el servidor.',
                    background: swalBg, color: swalColor 
                });
                btnSiguiente.disabled = false;
                btnSiguiente.innerHTML = originalText;
            });
        });
